# UI parity with the stock client

Screen by screen, what ours draws against what the stock client draws. The stock side is the back buffer of the stock client captured on 2026-09-15 with `tools/client_snap.ps1` and the pilot `shot` verb while `tools/stock_drive.py` drove it (`reference/stock`, ignored by git), or regenerated with `powershell -NoProfile -File tools/stock_docker/run.ps1 -Scenario refs`. Our side is `release\knc_client.exe --game <client> --state <name> --no-focus --screenshot out.png --frames 60`. Half size copies of the `<screen>_ours.png` set sit in [`parity/`](parity/), the `<screen>_stock.png` set is real game art so it lives in `reference/parity_stock/` instead, ignored by git, written there by the docker run above, a screen with one side only has one file. Every spot is in the 1024 by 768 game units, top left of the element. A spot marked `code` comes from the decompiled draw functions of `KnC.exe` (`_devclient_attic/KnC-new.exe.c`, the `sub_` names, or the Ghidra project `Reverse HBO`), a spot marked `capture` was measured on the stock picture.

How to compare one state: run `release\knc_client.exe --game <client> --state lobby`, run `tools\client_snap.ps1` while the stock client sits on the same screen, put `lobby.png` (F12) next to the capture.

The second pass of 2026-09-15 added the stock captures of the licence menu, the car factory, the gacha box, the escape menu, the shop item box, the track pick, the make room box, the inviting box, the whisper toggle, the lobby with no room and the creation popup of a fresh account (`reference/stock/14_licence_001.png`, `18_carfactory_002.png`, `8_lobby_gacha.png`, `8_lobby_escmenu.png`, `7_shop_popup.png`, `9_room_trackpick.png`, `8_lobby_makeroom.png`, `9_room_inviting.png`, `8_lobby_whisper.png`, `8_lobby_norooms.png`, `4_channel_creation.png`).
