## S2C RaceTimerArm

```
+0x00  u32  deadline_ms
size   4
```

Stores `deadline - latency_offset` where the offset is what S2C 0x000C wrote, then arms the
LapTime panel. If the local car is spawned it also sets car+2520 = 1, the flag the
0x0120 and 0x0121 checkpoint path is gated on, and fires camera event 1.
