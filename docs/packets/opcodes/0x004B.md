# 0x004B

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | HomingLaunchBroadcast | sub_47A460 | ItemPackets::homingLaunch | 16 | items | PROVEN |
| C2S | HomingLaunchRequest | sub_481320 | RaceHandler::handleHomingLaunch | 12 | items | PROVEN |

## S2C HomingLaunchBroadcast

```
+0x00  u32  sender_player_id    liveness gate only, value otherwise unused
+0x04  i32  item_kind           10 rocket, 16 magnet
+0x08  i32  shooter_player_id
+0x0C  i32  target_player_id
size   16
```

All four dwords read before the lookup, unknown ids are stream safe.
Any kind other than 10 or 16 is a no op.

## C2S HomingLaunchRequest

```
+0x00  i32  item_kind
+0x04  i32  shooter_player_id
+0x08  i32  target_player_id
size   12
```

Only sent when the lock state is 2 and the locked target index is >= 0.

## Our client

The shooter launches its own rocket or magnet in case 2 of `sub_4CA2A0` and `sub_4C6950`, the frame after the release set the lock to phase 2, and sends this packet from `FUN_004AEFA0` on the same release. Our server echoes the launch to the sender too (`RaceHandler::handleHomingLaunch`, its comment says `sub_481320` has no local launch), so a stock shooter would fly two. `RaceScreen` drops the echo whose shooter is the own player, the other racers launch it from their copy of the shooter.
