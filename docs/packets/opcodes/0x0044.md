## S2C LapBoardAdvance

```
+0x00  u32  unused   MUST be present, the reader advances 4, the value is never read
size   4
```

Promotes the running lap time into best, increments the row, resets the lap clock.
Total laps come from the track catalog +80 clamped 1..9, never from a packet.
Send once per completed lap, to the finishing player only.
