| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|

## S2C MakeRoomPopupOpen

```
+0x00  u32  game_mode_index   0..4
size   4
```

NOT a create room ack and it carries NO room id. The window is the MakeRoom popup.
0 item single, 1 item team, 2 speed single, 3 speed team, 4 battle.
Also calls `sub_4538B0` and sets max players 16 for modes 2 and 3 else 8.
Sending a room id here writes a garbage mode index. Room create is C2S 0x2D.

## Our server

Never sent. The 0x64 lobby quick match and two unrouted `LobbyHandler` create and join
paths used to answer with a 0x63 carrying the room id, which the client read as a mode
index and opened the MakeRoom popup with. Those senders and the
`PacketBuilder::createRoomResponse` builder are gone, a create refusal is a 0x02 text box
and a room enter is the [0x0013](0x0013.md) chain.
