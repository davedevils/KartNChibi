## S2C MissionDefinition

```
+0x00  blob[0xBC]  ONE mission definition, NO count prefix
size   188 fixed
```

All four strings are FIXED char[33] ASCII slots INSIDE the blob, NOT cstrs on the wire:

```
+0x00  u32       unused_00        no reader in this build
+0x04  u32       mission_id       lookup key of sub_450CA0
+0x08  u32       mission_kind     0, 1 or 2, S2C 0x0090 copies it to 0xD0955C
+0x0C  u32       unused_0C        no reader in this build
+0x10  i32       goal_count       sub_43AB00 and sub_439DB0
+0x14  i32       time_limit_ms    sub_43A150 sets deadline now+this, MUST be non zero
+0x18  u32       reward_extra     number drawn by sub_43C060 at y 0x26F and by the HUD sub_4B4350, label in the art
+0x1C  u32       reward_mileage   sub_43C060 composes `UNIT_MILEAGE %d` on it and draws the number at y 0x231, sub_46B2B0 draws it at x 0x267
+0x20  u32       reward_exp       sub_43C060 composes `UNIT_EXP %d` on it and draws the number at y 0x246, sub_46B2B0 draws it at x 0x1E5
+0x24  u32       unused_24        no reader in this build
+0x28  u32       reward_item_type 0..7, decides the S2C 0x8C tail size and the reward icon draw
+0x2C  u32       reward_item_key  catalog key of the reward icon
+0x30  u32       unused_30        no reader in this build
+0x34  u32       unused_34        no reader in this build
+0x38  char[33]  world_name       ASCII, `World/Mission/%s/track` in sub_488000
+0x59  char[33]  str_key_title    ASCII, sub_43C060
+0x7A  char[33]  str_key_sub      ASCII, sub_43C060
+0x9B  char[33]  str_key_desc     ASCII, HUD sub_4B4350, 0x9B+33 = 0xBC
```

The readers are every caller of sub_450CA0: sub_439DB0, sub_43A150, sub_43AB00, sub_43B7A0,
sub_43C060, sub_46B2B0, sub_47B9E0, sub_47DF30, sub_488000 and sub_4B4240 whose cached
pointer sub_4B4350 reads. None touches +0x00 +0x0C +0x24 +0x30 +0x34.
The wallet mapping: S2C 0x8C carries gold_after and exp_after, the client never adds the
two numbers itself. The UNIT_MILEAGE and UNIT_EXP labels are composed but not drawn in the
mission menu, the scenario HUD sub_4B5A00 draws the same pair with the labels. The server pays
reward_exp as exp and reward_mileage as gold, the gold half is the inference.
Container 0x01A4B468, HARD CAP 20, count at 0x01A4C31C.
Appends do NOT dedupe, send each definition EXACTLY ONCE per session.
Only S2C 0xBE clears it.
Stage 24 init preloads MissionMenu art per count, a missing file pops
`Stage MissionMenu initialize fail`.

## Our server

`MissionPackets::missionDefinition`, one frame per `mission_def` row on the first menu open.
`reward_extra` at 0x18 is the entry fee (the `Mission_Back` art and `MISSION_ENTER` name it),
migration 066 comments the column and [0x0090](0x0090.md) charges it. The kind at 0x08 picks
the world gimmicks of `world_gimmick_load_by_track` 0x4D4180: 0 the time items of
`Gimmick/gimmick_01.ini` (seven in ten) or `_02`, 1 the boxes of either file, 2 nothing, any
other kind never ends. Mission_05 ships only `gimmick.ini`, so its kind 0 row of our seed has
no gimmick file for the stock loader, kind 2 fits it; the seed is left as it is.
