## Our server

`CustomCarPackets::presetList` sends this from `CarCraftHandler::sendLoginSnapshot` after the
login burst, from `handleOpen` on stage entry and from `pushFactoryLoadout` after a chassis grant.
Rows come from `custom_car_preset`, the count is never zero.

### One slot per owned chassis, 2026-09-24

`CustomCarPackets::syncFactoryLoadouts` runs before the login burst builds 0x001C, in `buildView`
and after a grant. For every owned kart of an enabled factory template (`vehicle_templates.is_factory_car`),
in kart id order, 5 at most:

1. The kart goes on period mode 3 with 500 durability when it is on another mode.
2. `planFactoryPresets` keeps the first built row of each chassis. A chassis with no built row gets
   the BASIC set, `basicSetKeys` the lowest part key of each category 0 to 6 whose `model_dir_name`
   is the template name (Circler is Whirlwind, keys x002), each one a new permanent instance with
   grade 0, and a built row (slot_state 1, empty name, the seven instances). It reuses an empty or
   stale row first. A second row of one chassis, a row of a lost chassis and an empty row next to a
   chassis go. A player with no chassis keeps one clean empty row.
3. A built row whose tire is gone or expired takes the basic tire of its family, else any live tire,
   else a new basic tire (`pickTire`), since `sub_42F3E0` never saves a row with no tire.
4. The equip count of every part is recounted from the built rows (`refcountsFromPresets`).

The grants: `ShopHandler` `grantSimple` (buy, gift, `grantReward` of missions and quests) and
`GachaHandler` `grantKart` call `applyFactoryDurability`, so the 0x00B7 or gacha kart record already
carries mode 3 and 500. `handleBuy`, `handleRoll` and `handleMissionComplete` then call
`CarCraftHandler::pushFactoryLoadout`: the new 0x0109 rows, then this full replace, so the garage
lists the chassis at once. Migration 072 does the same to the rows already stored. Tests
`CarFactorySlots.*` and `ClientReaderRules.TheOfficialFactoryStreamIsClean`, which also flags an
owned chassis with no built row (`0x001C chassis has no built 0x0107 slot the garage never lists it`).

### The preset kart, 2026-09-23

`FUN_00430420`, the stage 18 car build, looks the preset kart up in the 0x001C list (null safe) and then its base
key in the 0x00C0 catalogue with no null test (`LEA EBP,[EAX+0x20]` at 0x43046E). A kart whose template is

no crash, so since the name plate fix below a built slot only ever names a factory chassis.
