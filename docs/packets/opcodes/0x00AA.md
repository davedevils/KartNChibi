## S2C GhostSessionStart

```
+0x00  u32           track_id
+0x04  UTF16LE wstr  ghost_name    28 byte field, CAP 13 wchars incl NUL, UNBOUNDED read
 var   u32           car_kind      only 3 and 4 are meaningful, else forced to 3
 var   i32           record_time_ms  INERT, no observable effect
 var   blob[0x2C]    character_block
 var   blob[0x38]    kart_block
size   112+2*(name+1)
```

SEND ORDER: S2C 0xAE first, then all 0xAF chunks, THEN this packet last.
The ghost car only spawns inside `if (frame_count > 0)`.
Past 13 wchars the name runs into the character block, past 63 it clobbers the race timer.
Offline fallback values: track 0, char {0,0,12000,12100,12200,-1,-1},
kart {0,0,1000,1100,-1}, name L"Gh", car_kind 3.
