## S2C gift lists, FULL REPLACE (family 0x0095 0x0096 0x0097)

```
+0x00  i32  count
 then  count x blob[0xD4] gift record
size   4+212*count
```

Record, from the renderer:

```
+0x00  u32        gift_id        key
+0x04  u32        category       0..6, selects the icon draw routine
+0x08  u32        item_base_key
+0x10  UTF16 wstr sender_name
+0x44  UTF16 wstr unknown col2 row1
+0x5A  UTF16 wstr unknown col2 row2
+0x6C  u8         read_flag
+0x6E  UTF16 wstr message        10 wchar preview then dots
+0xD0  u32        claimed_state  2 means claimed
```
