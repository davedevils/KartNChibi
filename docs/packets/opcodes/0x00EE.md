## S2C KartPeriodUpdate

```
+0x00  u32  player_id
 -- read ONLY when the id resolves to a live car --
+0x04  u32  purchase_option_key
+0x08  u32  period_mode
+0x0C  u32  period_value
+0x10  u32  active_flag
size   20
```

STREAM DESYNC RISK, the only one in this range. An unknown player_id consumes just 4 bytes
and leaves 16 in the buffer, corrupting every packet behind it in the same TCP read.
NEVER send it for a player not in the current car table.
CLIENT BUG: the 4 dwords are ALSO written unconditionally into the LOCAL player own owned
kart row +0x28 regardless of whose id the packet carried.
