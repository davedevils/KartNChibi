## Our server

`RoomCraftPackets::placedObject` builds one frame per row of `player_item_instance`
for the character. `RoomCraftHandler::pushOwnedInstances` sends them at login and on
stage open, deduped per session, and seeds a default sky and floor for a fresh
character first. They go out before the stage push, never while the client is in
stage 19.
