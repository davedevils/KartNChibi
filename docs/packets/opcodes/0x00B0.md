## S2C GhostSubmitResult

```
+0x00  u32         rank        1..3 shows a badge, anything else shows none
+0x04  blob[0xB0]  my_record
+0xB4  u32         top_count   NEVER send more than 3
+0xB8  min(top_count,3) x blob[0xB0]
size   184+176*min(top_count,3)
```

MANDATORY reply to C2S 0xB0, the client sits in state 2013 until it arrives.
The client clamps the loop to 3 so extra entries are memory safe but their BYTES ARE NOT
CONSUMED. The placement message counts how many of the THREE slots beat the run time,
a zero time_ms compares as faster than any run, so send 3 real rows.
