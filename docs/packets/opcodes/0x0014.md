## S2C SceneChange

```
+0x00  u32  scene_kind     -> 0xB2316C
 -- only when scene_kind is 3 or 8 --
+0x04  u32  unused_04      -> 0xB23170, no reader in this build, the handler write is its only xref
+0x08  u32  track_id       -> 0xB23174
+0x0C  u32  game_mode      -> 0xB23178
+0x10  u32  player_count   -> 0xB23198
+0x14  u32  flag           -> 0xB2319C, only tested against 1
size   4 when kind is not 3 or 8, 24 when it is
```

VARIABLE LENGTH BY VALUE. Sending 24 bytes with a kind other than 3 or 8 leaves 20 bytes
unread in the buffer. `sub_4028C0` wipes the whole 30 slot car table, so EVERY 0x3E must
come AFTER this. Sets conn+0x80E1B0 = -1, which 0x3C later reuses as finish_rank.
