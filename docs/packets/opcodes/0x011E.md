## S2C ServerRedirectStage11

```
+0x00  ASCII cstr  host   dest char[128]
 var   u32         port
size   strlen+5
```

THE HOST IS ASCII, NOT UTF16, and there is NO mode field, the target is hardcoded 11.
Next tick it disconnects and reconnects, on failure it retries the ini host and shows
MSG_SERVER_NOT_READY or MSG_CONNECT_FAIL, then sleeps 1000 ms and hands the new server the
stage 11 handshake.
Three redirects exist with different shapes: 0x0019 {cstr, u32, u32}, 0x0054 {u32, cstr,
u32}, 0x011E {cstr, u32}.
