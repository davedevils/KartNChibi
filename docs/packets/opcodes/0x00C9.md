## S2C PlaySoundCue

```
+0x00  u32  player_id
size   4
```

The 4 bytes are read BEFORE the lookup so an unknown id is a safe no op.
Plays the sound handle cached at car+0x2110, allocated at spawn from the player second
equipped item def through the 0xC1 catalog.
Stage 9 plays 2D, otherwise 3D at the interpolated car position.
The ONLY way to make a remote car emit that cue. No C2S counterpart.
