| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|

## C2S ReadyToggle

```
+0x00  u32  ready   the NEW value, 0 or 1
size   4
```

Rate limited client side to one per 200 ms.

## S2C ReadyStateChange

```
+0x00  u32  player_id   IGNORED when state == 2
+0x04  u32  state
size   8
```

state not 2: scans the 30 slots for occupied and matching id, writes slot.state.
state == 2: id ignored, sets state 2 on EVERY occupied slot. Identical to S2C 0x0034.
The only reader of slot.state is the host start gate. It is never rendered.
