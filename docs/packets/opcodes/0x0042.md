## S2C CameraMode or ResultBoard

```
+0x00  u32  mode
size   4
```

mode 5 opens the result board. Any other value sets the race camera and is rejected when
>= 8 or equal to the current mode. Known modes 0 free, 1 default, 2 chase, 3, 4,
6 wrong way, 7.
