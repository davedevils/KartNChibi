## S2C RoomMemberLeave

```
+0x00  u32  player_id
size   4
```

Clears occupied and sets team -1. It does NOT touch slot.enabled, so to grey a slot out
you must also send 0x0032 {slot, 0}. No C2S 0x22 exists.
