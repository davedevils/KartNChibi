## C2S BytesConsumedKeepalive

```
+0x00  u32  bytes_consumed_since_last_report
size   4
```

NOT a ping sequence. The counter accumulates `payload_len + 8` for every frame the client
dispatched. Sent at most once per 1000 ms, reset to 0 on connect and after every report.
The server correctly sends no reply.
