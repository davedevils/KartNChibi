The readers are every caller of sub_452E30: sub_42D690, sub_42E210, sub_4383D0, sub_438720,
sub_47DD10, sub_47DFA0 and sub_4B5D00 whose cached pointer sub_4B5A00 and sub_4B5EB0 read.
Container 0x01A64720, cap 50, stride 0x9C. The unused bytes only have to be byte stable.
The server table scenario_def carries no track_id, entry_fee, reward or string columns yet,
the builder sends 0 and empty slots for them.
