## S2C and C2S stage acks (family 0x011C 0x011D)

```
C2S 0x011C, 0x011D  payload none
S2C 0x011C, 0x011D  payload none, the packet argument is never read
```

S2C 0x011C pushes stage 22, S2C 0x011D pushes stage 23, both guarded on
dword_F727F4 != 2 then `sub_4538B0`.
0x011C extra side effect: if the PREVIOUS stage was 17 and two scenario globals are both
> 0 it also opens a result popup.
From stage 4 the client sends C2S 0x0018 {22 or 23, room_id} instead.
