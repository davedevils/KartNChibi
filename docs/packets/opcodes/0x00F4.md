## S2C ScenarioProgressList, FULL REPLACE

```
+0x00  i32  count   SIGNED, 0 or negative reads nothing
 then  count x { u32 scenario_key, u32 cleared_flag }
size   4+8*count
```

Memsets 0x190 and zeroes the count BEFORE the read. Cap 50, extra rows are consumed off the
wire then dropped, not overflowed. Re sorted after every insert.
The menu only lets you start stage i when the row for i+1 is absent or cleared.
