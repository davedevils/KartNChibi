## S2C UserInfoBlob

```
+0x00  blob[0x68]  profile, byte identical to the S2C 0x0028 blob
size   104
```

Known fields: +0x00 player_id, +0x04 wchar[13] name, +0x1E u16 level, +0x28 character_key,
+0x30 exp, +0x3C exp_floor, +0x40 exp_next, +0x48..0x60 stats, +0x64 pendant.
Renders INSIDE the messenger. The standalone popup is 0x0028.
