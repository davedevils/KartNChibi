# 0x002E

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | RoomListRowRemove | sub_479710 | PacketBuilder::playerLeft | 4 | lobby list | PROVEN |

## S2C RoomListRowRemove

```
+0x00  u32  room_id
size   4
```

Clears the active flag and resets the selection when that row was selected.

## Our server

Inside a room this opcode carries the leaver, not a lobby row. `PacketBuilder::playerLeft`
in `server/game/src/packets/PacketBuilder.cpp` builds it:

```
+0x00  i32  player_id   the character id that left the room
size   4
```

Three senders broadcast it to the rest of the room. `GameServer::leaveCurrentRoom` and
`GameServer::handleLeaveRoom` in `server/game/src/GameServerRoomHandlers.cpp` on a normal
exit, and the disconnect path in `GameServerBootstrap.cpp`. All three skip the broadcast
when the room is already empty, and `leaveCurrentRoom` removes the room instead.

`shared/src/include/net/Protocol.h` gives 0x2E two names for this reason, `S_PLAYER_LEFT`
and `S_LOBBY_ROOM_REMOVE`. The payload is the same one dword either way, so the receiver
tells them apart by its own stage, a room id while the lobby grid is up and a character id
while in a room.
