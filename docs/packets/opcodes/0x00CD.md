# 0x00CD

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | HitEffectApply | sub_47D1C0 | NONE | 8 | race items | PROVEN |
| C2S | HitAck or AbilityFire | sub_483180 | *ItemPackets::parseAbilityFire | 4 | race items | PROVEN |

## S2C HitEffectApply

```
+0x00  u32  player_id
+0x04  u32  hit_token
size   8
```

BOTH dwords are read before any lookup so an unknown id is stream safe.
`dword_5F1934` is ALWAYS set to the second field on both branches, and C2S 0x00CD echoes it
back, so the token is a per hit correlation id, not a friend id.

## C2S HitAck or AbilityFire

```
+0x00  u32  hit_token   the value the last S2C 0x00CD delivered
size   4
```

Sent by the LOCAL car only, for gimmick or ability classes 0 4 5 6 7 23.
If the server never sent a 0x00CD the client still sends whatever the global holds, 0 at
boot.
