## C2S LeaveRace

```
payload none
```

The race exit. Handled since 2026-09: retire dock, room leave, then S2C 0x12 so the client goes to the lobby, the sender only writes the frame and waits.
On the confirm path the client applies a LOCAL retire penalty when more than one car is in
the race: exp -= 3 and gold -= 6, both clamped at 0. Mirror it or the HUD disagrees.
