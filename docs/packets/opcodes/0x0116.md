## S2C WaitRoomSideListAdd

```
+0x00  u32           player_id   -> slot+0x04
+0x04  UTF16LE wstr  name        -> slot+0x08, CAP 13 wchars plus NUL, wcscpy into a 28 byte slot
 var   u8            kind        -> slot+0x24, sub_40E430 at 0x40F37E draws the slot only when it is 6
size   4+2*(n+1)+1
```

8 slots, stride 40, base room+0x1CC98, sub_40F550 fills the first free one.
The only reader of kind is the room draw loop `if (slot+0x00 && slot+0x24 == 6)` which prints
the name at x 0x387, nothing else reads the byte so values other than 6 just hide the row.
Returns without doing anything when the room is not initialised or all 8 slots are taken.
Longer names overrun the kind field and the next row.
