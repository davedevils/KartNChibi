## S2C RoomCraftStagePush

```
payload none, zero reads
```

No op when dword_F727F4 == 2. Otherwise stage 19 then close popups.
0x010C and 0x010D must be complete BEFORE this.

## Our server

C2S 0x010E routes to `RoomCraftHandler::handleOpen`. It pushes the missing 0x010C
catalog and 0x010D owned rows, then the empty 0x010E ack and the stage push last.
This is what the stock client was missing, without the answer the Room Craft button
left it in the lobby. The catalog and the owned rows already went out at login so a
resend is usually empty.
