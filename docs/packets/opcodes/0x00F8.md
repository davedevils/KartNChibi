# 0x00F8

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | ScenarioResult reward | sub_47DFA0 | ScenarioPackets::scenarioResult | 13, 21 or plus tail | scenario | PROVEN |
| C2S | ScenarioResultReport | inline sub_42E330 | ScenarioHandler::handleScenarioResultReport | 8 | scenario | PROVEN |

## S2C ScenarioResult or AchievementReward

```
+0x00  u32  kind           -> 0xC70A38, write only
+0x04  u8   flag           -> 0xC70A34, no reader in this build
+0x05  u32  scenario_key   the progress row lookup key
+0x09  u32  unread
 -- only when kind is 2 or 3 --
+0x0D  u32  -> 0x01A20B14 gold
+0x11  u32  -> 0x01A20B0C exp
 -- only when kind is 3 --
 var   typed reward record chosen by the 0x00F3 definition +0x28, NOT by the wire
size   13 for kind 0, 1 or above 3, 21 for kind 2, 21 plus tail for kind 3
```

The success or failed text is NOT picked by the flag: sub_42E330 shows MSG_QUEST_SUCCESS when
the stage's own result byte at +0x1D4 is 1 and MSG_QUEST_FAILED otherwise, before this frame
even arrives. 0xC70A34 has only the handler write.

```
0 -> blob[0x2C] character
1 -> blob[0x38] kart
2 -> blob[0x1C] item
3 -> blob[0x1C] part
4 -> blob[0x1C] pet, container 0x857258
5 -> blob[0x30] roomcraft
6 -> blob[0x84] carcraft THEN u8 has_slot THEN blob[0x34] when has_slot == 1
7 -> blob[0x08] pendant { pendant_instance_id, pendant_key }, sub_451250 removes the key then sub_451140 appends
8 and above -> nothing
```

THIS REWARD ENUM IS NOT THE 0x00B7 ENUM AND NOT THE 0x00ED ENUM. It has an extra case 4 and
shifts roomcraft to 5 and carcraft to 6.
NULL DEREF RISK on kind 2 and kind 3: `*(lookup(scenario_key)+4) = 1` with NO null check,
a key with no 0x00F4 progress row writes to address 4.
The tail selector comes from the CLIENT copy of the definition, server and client must
agree or the frame desyncs.

## C2S ScenarioResultReport

```
+0x00  u32  scenario_key
+0x04  u32  result_value
size   8
```

The client is stuck in state 2013 until S2C 0x00F8 arrives, it never times out.
