## S2C ServerClockSync

```
+0x00  blob[0x24]  a C struct tm, nine i32:
       +0x00 tm_sec  +0x04 tm_min  +0x08 tm_hour  +0x0C tm_mday  +0x10 tm_mon
```

IDENTIFIED BY ITS CONSUMER: the day index is `365*tm_year + tm_yday - 365`, the same
expression the localtime fallback uses. That index is what every period_mode 1 absolute day
item is compared against. Send it once at login BEFORE any owned list.
