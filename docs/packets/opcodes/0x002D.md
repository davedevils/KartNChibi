# 0x002D

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | RoomListRowAdd | sub_479630 | PacketBuilder::lobbyRoomAdd | 32+2*(n+1) | lobby list | PROVEN |
| C2S | CreateRoomRequest | sub_480CC0 | GameServer::handleCreateRoom | 16+2 strings | lobby list | PROVEN |

## C2S CreateRoomRequest

```
+0x00  UTF16LE wstr  room_name
 var   UTF16LE wstr  password      empty is exactly 2 zero bytes
 var   u32           max_players   8 or 16, forced by the mode radio
 var   u32           game_mode
 var   u32           has_password  0 or 1
 var   u32           channel       always 0, sub_408EB0 is `return 0`
size   16+2 strings
```

TWO wide strings back to back. Client refuses to send on a taboo hit
(MSG_INVALID_ROOM_NAME type 2) or an empty name (MSG_NEED_ROOM_NAME type 1).

## S2C RoomListRowAdd

```
+0x00  u32           room_id       -> rec+0x04, drawn as room_id+1 in front of the name
 var   UTF16LE wstr  room_name     dest wchar_t[42] then an 84 byte record slot at rec+0x08
 var   u32           player_count  -> rec+0x5C, left number of the `%2d/%2d` at sub_407E4E
 var   u32           max_players   -> rec+0x60, right number of the same `%2d/%2d`
 var   u32           game_mode     -> rec+0x68, 0..4 picks Lobby_Room_I_Single I_Team S_Single S_Team B icon, other values hide the row
 var   u32           has_password  -> rec+0x6C, 1 draws Lobby_Room_Lock at sub_407E1E
 var   u32           channel       -> rec+0x70, row drawn only when equal to sub_408EB0 which is 0
 var   u32           playing_flag  -> rec+0x74, 0 draws the Item or Speed background, else Lobby_Room_Play and the grey icon
 var   u32           time_left_ms  -> rec+0x78, countdown drawn only on channel 3 at sub_407CD2
size   32+2*(name+1)
```

One packet per room row. Table is 512 records of stride 136 at stage+0x6820, sub_408360 stores.
The row draw is sub_407B50, the list draw sub_407EA0, the mode 2 and 3 rows use the Speed art.
player_count and max_players are what S2C 0x0031 rewrites, playing_flag is what S2C 0x0023
rewrites, has_password is what S2C 0x0118 kind 1 rewrites.
All rows must arrive BEFORE the 0x0012 lobby ack.

## Our server

C2S: `GameServer::handleCreateRoom` in `server/game/src/GameServerRoomHandlers.cpp`. It
reads the two wide strings and the four dwords, caps the seats at 8 or 16 by mode, picks
the first race track with a map link, opens the room, seats the creator as master, calls
`Room::fillWithBotsIfEnabled` which is a no op here since an explicit create never sets
`RoomSettings::fillWithBots`, and sends the [0x0013](0x0013.md) chain through
`GameServer::sendRoomScreen`, the same chain a joiner gets. No 0x63 and no 0x3F, a refusal
is a 0x02 text box.

S2C: `GameServer::sendLobbyRoomList` drips one 0x2E then one 0x2D per live room after every
0x12 lobby ack, `PacketBuilder::lobbyRoomAdd`.
