# 0x000E

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | ChannelList | sub_4793F0 | PacketBuilder::channelList | var | channel | PROVEN |

## S2C ChannelList

```
+0x00  i32  channel_count
 then  count x {
          u32           channel_id
          UTF16LE wstr  channel_name   dest wchar_t[256] then a 128 wchar record slot
          u32           population
          u32           capacity
          u32           channel_tier
       }
 then  UTF16LE wstr  notice_text   read UNCONDITIONALLY even when count is 0, NO bound
size   4 + sum(12+2*(name+1)) + 2*(notice+1)
```

This is the packet that moves the client to the channel screen. Ends with stage 4 then
`sub_4538B0`. If a row overflows the 80 entry list the client shows MSG_UNKNOWN_ERROR
type 2 and DISCONNECTS. channel_tier seen 0, 1, 2.
