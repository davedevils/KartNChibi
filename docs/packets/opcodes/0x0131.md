## S2C ItemRollStream

```
+0x00  100 x u32   fixed, NO count prefix
size   400 exactly
```

The array is a RING consumed one entry per item box pickup:
`v4 = table[idx++]; if (idx > 99) idx = 0; if (v4 >= itemdef[1]) return 0;`
The server hands the client a pre rolled random stream and the client compares each draw
against the item definition weight at def+0x04.
The granted item is echoed back with C2S 0x00CD.
This array sits immediately after the S2C 0x0120 checkpoint array, an oversized 0x0120
corrupts it.
