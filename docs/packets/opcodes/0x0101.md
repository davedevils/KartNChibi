## S2C QuestComplete

```
+0x00  u32  quest_index
+0x04  u32  progress_count
size   8
```

Writes rec+0x08 = progress and rec+0x04 = 2. NO NULL CHECK, an index not already in the
client state list writes to absolute addresses 4 and 8 and access violates.
Send S2C 0x00FC or 0x00FE first.
