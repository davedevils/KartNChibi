## S2C CarCraftOpenAck

```
payload none, the reader is called ZERO times, any payload is wrong
```

No op when dword_F727F4 == 2. Otherwise snapshot, stage 18, close popups.
Stage 18 init snapshots the preset, def and instance containers, so 0x0107 with count >= 1,
every 0x0108 and every 0x0109 must already be buffered.

## Our server

C2S 0x010A routes in `GameServerDispatch.cpp` to `CarCraftHandler::handleOpen`. It
resends the part defs, the owned part instances and the preset list, then answers
the empty 0x010A ack. Equip install and remove are client local, they only mutate
the in memory car config, the exe ships that config on the Save button as 0x010B.

The open runs `syncFactoryLoadouts` first, so the 0x0107 carries one built row per owned chassis
with its BASIC set, and a player with no chassis gets the one empty row (slot_state 0, no name,
kart 0): no car, empty bars, the grey plate. The open never refuses, see [0x0107](0x0107.md).
