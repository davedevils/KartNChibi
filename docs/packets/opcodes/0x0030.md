## S2C ReadyReset plus ROOM MASTER OVERWRITE

```
+0x00  u32  player_id
size   4
```

MAJOR GOTCHA, `0x00479766 PUSH 0xbce220`: the u32 is read STRAIGHT INTO dword_BCE220,
the SAME global 0x0013 fills with master_player_id. Sending 0x0030 silently makes that
player the room master. It then walks all 30 slots and clears ready_state where the id
matches. No occupied check and no init flag guard.

## Our server

Sent once per room chain after the 0x21 members, `GameServer::sendRoomScreen` in
`server/game/src/GameServerRaceHandlers.cpp`, with `Room::hostCharacterId()`. It is never
the id of the receiver, a joiner and a member after the results get the real master, since
the value overwrites `0xBCE220` and the start button follows it.
