## S2C ReplayFrameCountAlt and 0x00F7 S2C ReplayFrameChunkAlt

```
0x00F6  +0x00 u32 frame_count                      size 4
0x00F7  +0x00 i32 count, then count x blob[0x1C]   size 4+28*count
```

Same shape and meaning as 0x00AE and 0x00AF but they target the SCENARIO stage replay car
slot instead of ghost stage 15. 0x00F6 resets the write cursor so it MUST precede 0x00F7.
NO BOUNDS CHECK on the cursor, keep the running total at or below 24000 frames.
Frame cadence 20 ms in stage 13, 200 ms everywhere else. Max 292 frames per packet.
