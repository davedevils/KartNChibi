## S2C GhostFrameChunk and 0x00AF C2S ReplayUploadChunk

```
+0x00  u32  n
 then  n x blob[0x1C] ReplayFrame
size   4+28*n, max n 292 per frame, the client uploader chunks at 136
```

ReplayFrame:

```
+0x00  f32  pos_x
+0x04  f32  pos_y
+0x08  f32  pos_z              Z is up
+0x0C  u8   yaw                deg * 255/360
+0x0D  u8[3] pad
+0x10  u32  flags
+0x14  u32  steer_speed_nibbles
+0x18  u8   input_mask
+0x19  u8[3] pad
```

The cursor is NOT bounds checked. Total appended frames must stay <= 24000, in practice
<= 2400. Same array a .rep file fills, same consumer.
