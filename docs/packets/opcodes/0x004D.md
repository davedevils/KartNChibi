## S2C ClientInfoProbe and 0x004D C2S ClientInfoBlob

```
S2C  payload none, pure trigger, the handler never touches the cursor
C2S  +0x00 blob[0x114] verbatim copy of the static buffer at VA 0x005DE9DC
size C2S 276
```

The 276 byte source is ALL ZERO in the image and its only xref is the write inside the
handler itself. Nothing ever fills it. Always 276 zero bytes. Treat it as a ping ack,
there is no hardware id and no version in it.
