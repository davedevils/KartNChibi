## S2C PositionFixBulk

```
+0x00  i8  count   SIGNED, 0x80..0xFF means zero iterations
 then  count x { u32 player_id, u64 packed_position }
size   1+12*count
```

NOT a license opcode. Position only bulk correction into the same interpolation slot as
0x40, with flag 0 so the client recomputes the extrapolation target from its own velocity
and SKIPS yaw and state bits entirely. Both reads happen before the lookup.
