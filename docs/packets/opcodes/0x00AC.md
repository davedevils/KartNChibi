## S2C GhostBoardTrack

```
+0x00  u32         track_id      READ AND DISCARDED, the client keys off arrival ORDER
+0x04  blob[0xB0]  track_best RecordEntry
+0xB4  u32         entry_count
+0xB8  entry_count x blob[0xB0] RecordEntry
size   184+176*entry_count
```

GUARD at `0x0047CA11 CMP EAX,ECX / JGE ret`: if the fill index already reached the count
announced by 0xAB the WHOLE packet body is DROPPED WITHOUT READING, which desyncs the
frame. Send exactly track_count packets in the client track table order.
Storage cap is 30 entries per track, the read loop is unbounded, the frame cap gives 45.
RecordEntry: the client only ever reads a NUL terminated UTF16 name at +0x04 and an
i32 time_ms at +0xAC. Bytes +0x00 and +0x08..+0xAB are never read.
time_ms <= 0 renders as dashes.
