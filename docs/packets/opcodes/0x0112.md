## S2C ShopExtendOk

```
+0x00  u32  category
+0x04  u32  gold
+0x08  u32  astro
 -- category 5 only --
+0x0C  blob[0x30]  room craft record
size   12, or 60 for category 5
```

CURRENCY ORDER is (gold, astro) like 0x00B7, REVERSED versus 0x0098.
Closes MSG_WAIT FIRST then reads. Always ends with MSG_SUCC_BUY, no failure variant.
The category 5 tail does an UNGUARDED 0x30 qmemcpy after the lookup, an unowned uid null
derefs the client.
