# 0x0081

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | MessengerResult | sub_47B8A0 | SocialPackets::messengerResult | 4 | messenger | PROVEN |
| C2S | NoteSend | sub_4825F0 | SocialPackets::parseNoteSend | 2 strings | notes | PROVEN |

## S2C MessengerResult

```
+0x00  u32  message_code
size   4
```

Sets the messenger page selector to 7 and stores the code. Same code table as 0x6F and
0x74. For the note flow use 7 to 11. Codes outside 0..11 leave the page blank.

## C2S NoteSend

```
+0x00  UTF16LE wstr  recipient_name   source field 26 bytes, 13 wchars incl NUL
 var   UTF16LE wstr  body             source field 0x140 bytes, 160 wchars
size   2*(n+1)+2*(m+1)
```

BOTH strings are UTF16, not ascii. Body is pre processed so single quotes arrive doubled.
Reply with S2C 0x0081 code 10 on success, 9 or 11 on failure.
