## S2C GiftClaimAck

```
+0x00  u32  gift_id
+0x04  u32  category
+0x08  reward record chosen by category
size   8, or 8 plus the record
```

```
0 -> blob[0x2C] character
1 -> blob[0x38] kart
2 -> blob[0x1C] item
3 -> blob[0x1C] part
5 -> blob[0x30] roomcraft
6 -> blob[0x84] carcraft + u8 hasExtra [+ blob[0x34]]
4, 7 and anything above 6 -> READS NOTHING
```

DESYNC TRAP: unlike 0x8C and 0x00A3 this switch has NO case 4 and NO case 7.
Grant a pet or a stackable through 0x8C, 0x00A3 or 0x00B7 instead.
Sets rec+0xD0 = 2, the row is NOT removed.

## C2S GiftClaim, 0x009B C2S GiftDelete, 0x009C C2S GiftMarkRead

```
+0x00  u32  gift_id
size   4 each
```

S2C 0x009B removes the row and compacts. S2C 0x009C sets rec+0x6C = 1, null safe.
0x009C only fires once, when an unread row is clicked.
