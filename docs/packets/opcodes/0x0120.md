## S2C MissionCheckpointPath

```
+0x00  i32  count
 then  count x { f32 x, f32 y, f32 z }
size   4+12*count
```

NO CAP AND NO BOUNDS CHECK, the wire count is the only loop bound.
Only 12 slots fit before it overwrites the latency offset and then the 100 dword item roll
table from S2C 0x0131. KEEP count <= 11.
The HUD index is clamped to 11 anyway. The 3D marker is drawn at z+10.0.

## Our server

Not a mission packet: the only 0x0121 sender runs in stage 11 on the rally world of track key
20000000, and 0x0120 writes an unbounded count into 12 slots. Until 2026-09-22 the mission
start sent 0x0120 and 0x0122, the new image sends neither and our client ignores them in
stage 25.
