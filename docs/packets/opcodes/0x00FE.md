## S2C QuestAcceptAck and 0x00FE C2S QuestAccept

```
+0x00  u32  quest_index
size   4 in BOTH directions
```

The S2C handler SYNTHESISES the whole 12 byte state row locally, state hardcoded 1 and
progress 0, only the index comes off the wire.
NO DUPLICATE CHECK, a repeated ack adds a second row and burns a slot.
C2S gates: no row already in state 1, no existing row for this index, index >= 0.
Answer on success ONLY, and never twice for the same index.
