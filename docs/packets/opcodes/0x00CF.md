| Direction | Name | Client fn | Server symbol | Size | System | Status |

## S2C ItemSlotSet and 0x00CF C2S ItemSlotReport

```
S2C  +0x00 u32 player_id, +0x04 u32 slot0, +0x08 u32 slot1, +0x0C u32 slot2   size 16
C2S  +0x00 u32 slot0, +0x04 u32 slot1, +0x08 u32 slot2                        size 12
```

-1 means empty. All four S2C dwords are read before the lookup, unknown id is stream safe.
Exact mirror, the local client applies the same values itself after sending.
Relay by rebuilding with the sender id prefixed, to every OTHER client.
