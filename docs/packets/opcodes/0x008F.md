## S2C MissionMenuAck and 0x008F C2S OpenMissionMenu

```
both  payload none
```

S2C pushes stage 24 then `sub_4538B0`, no op while dword_F727F4 == 2.
C2S gate: byte_11C028C not 1, and level >= 10 or license grade >= 1, and not already in
stage 24. MSG_WAIT is already up so the server MUST answer.

## Our server

`MissionHandler::handleOpenMissionMenu`: the defs once per session, the progress list cut after the
first row not cleared (`MissionPackets::chainProgress`, see [0x0088](0x0088.md)) and the ack. The ack is
answered once per open. A second ack in stage 24 is harmless anyway: `FUN_00404410` returns at once when
the stage asked is the current one (0x18 is none of the stages 0xB 0xD 0xF 0x11 0x19 it re checks).
Stage 24 draws no 3D: `FUN_0043BAD0` loads only 2D art, the update is the empty `FUN_004EA1D0`, and the
preview renderer `FUN_004A50A0` has two callers, the char panel `FUN_0042AB70` (lobby, garage, shop) and
the licence menu `FUN_00437820`. The Escape box of stage 25 sends this 0x008F to leave a run, so since 2026-09-23 the open
also drops the `char_mission_state` row of a run left half way.
