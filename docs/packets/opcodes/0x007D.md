## S2C SmallTalkInvite

```
+0x00  u32           requester_id
+0x04  UTF16LE wstr  requester_name
size   4+2*(len+1)
```

SUPPRESSED entirely while in a race or while any modal flag is set, the id and name are
still stored. Conversation text later arrives on S2C 0xB4 with chat_type 4.
LIVE SERVER BUG: `PacketBuilder::notification` builds 0x7D as {i32 type, wstring msg} which
is exactly this layout, so every lobby notice currently pops a SmallTalk invite.
