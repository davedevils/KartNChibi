## C2S MissionCheckpointReached

```
+0x00  u32  new_checkpoint_index   AFTER the client incremented it
size   4
```

Fires within 18.0 units of the current checkpoint, gated on car+2520 == 1 and car+2521 == 0.
Purely client authoritative, validate it.

## Our server

Not a mission packet: the only 0x0121 sender runs in stage 11 on the rally world of track key
20000000, and 0x0120 writes an unbounded count into 12 slots. Until 2026-09-22 the mission
start sent 0x0120 and 0x0122, the new image sends neither and our client ignores them in
stage 25.
