## C2S ScreenDataRefresh and 0x00FA C2S ScreenDataRequest

```
both  payload none
```

Both are sent at the tail of the lobby, ScenarioMenu and MissionMenu stage inits, 0xFA
first then 0x8E on the next line. Neither has an S2C handler.
The response set is INFERRED. Current server choice: 0xFA answers with S2C 0x000A,
0x8E answers with the S2C 0x88 full replace.
