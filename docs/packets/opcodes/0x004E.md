# 0x004E

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | DelayedAckArm | sub_479160 | PacketBuilder::timestamp | 0 | keepalive | PROVEN |
| C2S | DelayedAckFire | sub_485290 | NONE | 0 | keepalive | PROVEN |

## S2C DelayedAckArm and 0x004E C2S DelayedAckFire

```
both  payload none
```

S2C sets conn+0x8CCD8C = 1 and stamps a u64 timestamp. The C2S fires exactly once,
15000 ms later, then clears the flag so it never repeats until re armed.
