## C2S BoostReadyFlag and 0x0125 S2C BoostReadyRelay

```
C2S  +0x00 u8 boost_ready                      size 1
S2C  +0x00 u32 player_id, +0x04 u8 boost_ready size 5
```

Exactly ONE byte on the wire in the C2S direction even though the caller passes an int.
Edge triggered only, with a local debounce, so it never repeats.
S2C reads both fields before the lookup, unknown id is safe.
Relaying a player his own flag is harmless but pointless.
