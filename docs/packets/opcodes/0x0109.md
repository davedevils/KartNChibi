## S2C CarCraftPartInstance

```
+0x00  blob[0x84]  one part instance, NO count prefix
size   132 exactly
```

```
+0x00  u32  instance_id
+0x04  u32  part_key        must resolve in 0x0108
+0x08  u32  category
+0x0C  i32  equip_refcount
+0x80  i32  grade
```

Appends into 0x01A8B334, cleared at connect by 0x00BE. One packet per owned part.
This is the ONLY path that pushes a grade change, the 0x010B ack only patches +0x0C.

```
+0x10  u32  price key, not read
+0x14  u32  period type  0 permanent 1 day number 2 times 3 durability
+0x18  i32  period value
+0x1C  u32  active       0 draws UNIT_EXPIRED and blocks the install
```

Stage 18 part rows (`FUN_0042FE20`): every owned instance of the tab category is its own row, three
rows of 64 from 435. The icon by grade tier at 58, `"%s - %s"` of the 0x0108 name and the grade word
(`CAR_PART_BASIC` under 5, `_UNIQUE` under 20, `_EPIC` up to 64, `_LEGEND`) at 134 plus 12, the period
words of `FUN_00454A10` at 146 plus 38 (`UNIT_PERMANENT`, `%4d` days left, `%4d` times, `%4d` dur),
the magnifier at 340 plus 36. The in use art goes on a row whose key is the key of the part in the
slot, or whose +0x0C is above 0 with +0x1C 1. No number is drawn from +0x0C or +0x80 in this build,
the `+1` `+2` of the video is not in this exe. Install (`FUN_0042F6C0`) adds 1 to +0x0C of the new
part and takes 1 off the old one, so +0x0C counts the slots that hold the part.

## Our server

`CustomCarPackets::partInstance` builds one frame per owned part from
`custom_car_part_instance`. `CarCraftHandler::sendPartInstances` sends only ids
this session has not seen, so a reopen adds nothing.

Since 2026-09-24 +0x0C is the number of built 0x0107 rows that hold the part (`syncRefcounts`,
`refcountsFromPresets`), it used to be 0 or 1. A chassis grant adds its BASIC set, seven permanent
instances of grade 0, so one key can have several instances: migration 072 drops the
`uq_part_char_key` key. A shop buy of a key the player owns still renews the first instance, the
0x00B7 category 6 reader erases by key before it appends.
