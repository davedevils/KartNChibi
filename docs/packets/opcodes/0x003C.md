## S2C FinishAndReward

```
+0x00  u32  player_id
+0x04  u32  gold_after
+0x08  u8   level_after
+0x09  u32  exp_after
+0x0D  i32  finish_rank
size   17, PACKED and genuinely unaligned
```

SEND UNICAST TO THE FINISHER ONLY. gold, level, exp and rank are written into the
RECIPIENT account globals with NO id guard, broadcasting overwrites every HUD wallet.
Other clients learn the finish from 0x58 and 0x3D.
When the id resolves the client stops sending C2S 0x67 for itself and replies C2S 0x58 {9}.
rank 0 plays goal_winner_snd.wav, non zero plays goal_finish_snd.wav.
