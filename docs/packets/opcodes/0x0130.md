# 0x0130

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | no case | none | NONE | n/a | options | NO CASE |
| C2S | Option11Report | sub_483C10 | NONE, DATA_REQ16 swallow | 4 | options | PROVEN |

## C2S Option11Report

```
+0x00  f32  option_11   raw float bits, NOT an int
size   4
```

Sent unprompted on lobby entry and every time the options screen closes.
0.0 means the client will show room invites, anything else means it drops them silently.

## Our server

C2S 0x0130 routes to `case C_LOBBY_TELEMETRY` in `GameServerDispatch.cpp`. The float is read,
`inviteOptOutFromOption11` turns anything but zero into an opt out, and the value is kept on the
session. When it changes it is written to `accounts.invite_opt_out`, migration 065, so the
setting survives a relogin and a channel return. The login burst reads the column back into the
session, the client then confirms it with its own 0x0130 a moment later.

There is no S2C answer, the client expects none. The stored value is read by the random invite
picker only, see [0x012F](0x012F.md).
