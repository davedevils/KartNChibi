# 0x00B4

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | ChatBroadcast | sub_47CD60 | *SocialPackets::chatBroadcast | var | chat | PROVEN |
| C2S | ChatSend | sub_480990 | *SocialPackets::parseChatSend | 2*(n+1)+4 | chat | PROVEN |

## S2C ChatBroadcast

```
+0x00  u32           player_id
+0x04  UTF16LE wstr  sender_name   dest 28 bytes, CAP 13 wchars incl NUL
 var   UTF16LE wstr  text          dest wchar[8192]
 var   u32           chat_type
size   4+2*(n+1)+2*(m+1)+4
```

chat_type: 0 normal `name : text` and in stage 9 also raises the 3D bubble,
1 silently dropped, 2 raw text colour 2 with no name prefix, 3 big on screen notice,
4 routed into the SmallTalk popup, above 4 dropped.
Target window by stage: 8 lobby, 9 room, 11 race.
HARD LIMIT: the composed line lands in wchar Buffer[256], so len(name)+3+len(text) <= 255.

## C2S ChatSend

```
+0x00  UTF16LE wstr  text
 var   u32           chat_type   always 0 from the client
size   2*(n+1)+4
```

Whisper and team chat are NOT separate opcodes. The client concatenates the command prefix
into this same wstring, `/w name text` and `/t text`, and THE SERVER parses the token.
Text is already profanity masked before the packet is built.
Anti flood is client side only, 5 sends inside 2000 ms self mutes for 60000 ms.
