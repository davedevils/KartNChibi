## S2C CarCraftPresetRenameAck

```
+0x00  u32         preset_id
+0x04  ASCII cstr  new_name   local dest is only 12 bytes
size   4+strlen+1
```

TWO HAZARDS. The preset lookup result is used with NO null check, an unknown preset_id
writes to address 8. The copy loop runs to the NUL with no cap into a 12 byte slot bounded
by the kart_instance_id field. CLAMP TO 9 CHARS PLUS NUL SERVER SIDE: 11 fit the slot but the
next name plate click widens the name into a 10 WCHAR stack cell and overruns, see 0x0107.

## Our server

C2S 0x0114 routes to `CarCraftHandler::handleRename`, the name is cut to
`CustomCarPackets::PRESET_NAME_MAX` 9 before the write, the ack and the 0x0124 row update.
An unknown preset id answers MSG_UNSUPPORT and no ack.
