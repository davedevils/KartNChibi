## S2C FriendStatusFull

```
+0x00  i32  count
 then  count x { u32 friend_player_id, i32 status_a, i32 status_b }
size   4+12*count
```

status_a lands at rec+0x24, status_b at rec+0x28. rec+0x28 has no reader in this build, see 0x0076.
BEFORE the loop it resets status_a and status_b to -2 on EVERY friend record, so send only
the online friends and every omitted friend renders offline.
CRASH RISK: the lookup returns 0 on a miss and the handler writes *(0+36) and *(0+40) with
NO null check. A status row for an id not already in the friend list null derefs the client.
Push 0x76 first.

## C2S FriendStatusPoll

```
payload none
```

Fires every 3000 ms while the messenger window is visible. Keep the answer cheap.
