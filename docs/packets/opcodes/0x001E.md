## S2C OwnedPartRecord, SINGLE record, NO count

```
+0x00  blob[0x1C]   one owned part record
size   28 exactly
```

```
+0x00  u32  instance_id
+0x04  u32  part_base_key   0xC2 catalog, sub_450E90 finds the row by it
+0x08  u32  unused_08       no reader in this build, the client only echoes it in C2S 0x00CC
+0x0C  u32  price_key       0xC6 price row key, garage sub_415FF0 and sub_472490 draw the price triple from rec+0x0C, shop sub_45E3D0 resolves it
+0x10  u32  period_mode     2 means the part reports use through C2S 0x00CC
+0x14  u32  period_value    durability or remaining uses, car_has_ability decrements it on mode 2
+0x18  u32  active_flag
```

The part row readers are sub_415FF0, sub_416D60, sub_472490, sub_482DB0, sub_482FE0 and
car_has_ability, none reads +0x08.
THE ONE COUNTLESS LIST OPCODE IN THIS RANGE. Handler removes any record whose key equals
rec+0x04 then appends. Send one packet per owned part. Container 0x01A584E0, cap 256.
S2C 0x009F appends to the same container WITHOUT the remove step.
