## S2C ForceJoinInvitedRoom and 0x006E C2S JoinInvitedRoom

```
S2C  payload none, pure trigger
C2S  +0x00 u32 room_id, +0x04 UTF16LE wstr room_password, max 9 units
size C2S 4+2*(pw+1)
```

S2C replays the room_id and password the LAST 0x6C or 0x134 left in the globals.
Sending it without a preceding 0x6C makes the client join with stale values.
Password is UTF16, not ascii. Second join path alongside C2S 0x2F.

## Our server

C2S 0x006E routes to `GameServer::handleJoinRoom`, the same seat and 0x0013 chain as
0x002F. It carries the room id and the wide password the last 0x006C left, so an
accepted invite lands the player in the inviter room.
