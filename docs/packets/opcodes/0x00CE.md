# 0x00CE

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | SystemMessage | sub_47D250 | NONE | var | chat | PROVEN |

## S2C SystemMessage

```
+0x00  ASCII cstr    message_key   dest char[64], CLAMP TO 63
 var   UTF16LE wstr  arg_string    dest 28 bytes, CLAMP TO 13 wchars
 var   u32           arg_int
size   strlen(key)+1+2*(wlen+1)+4
```

MIXED ENCODING, ASCII first then UTF16. All three fields are consumed unconditionally
before any key comparison, so an unknown key stays aligned and prints nothing.
Keys that format BOTH args: MSG_COME_IN_FIRST, MSG_COME_IN_SECOND, MSG_COME_IN_THIRD,
MSG_COME_IN_OTHER. Keys that use the wstring only: MSG_BECOME_OWNER, MSG_LEFT_ROOM,
MSG_LEVEL_UP, MSG_DURABILITY_SCROLL.
