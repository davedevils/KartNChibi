## S2C UserInfoPopup

```
+0x00  blob[0x68]   profile, no strings on the wire
size   104 exactly
```

`blob+0x00` is the ACCOUNT id, compared against `dword_1A20668` which is 0x0007 blob+0x000.
If it matches, only a Close button is shown, else Close plus Add Friend.
If the popup art fails to load the client QUITS. Natural reply to C2S 0x0026, 0x0072
and 0x0133.
