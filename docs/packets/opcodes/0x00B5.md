# 0x00B5

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | WhisperDeliver | sub_47CF80 | *SocialPackets::whisperDeliver | 2448+2*(n+1) | whisper | PROVEN |
| C2S | WhisperSend | sub_480C00 | *SocialPackets::parseWhisperSend | 4+2*(n+1) | whisper | PROVEN |

## S2C WhisperDeliver

```
+0x0000  blob[0x4C8]   sender_user_info     same struct as the 0x0007 blob
+0x04C8  blob[0x4C8]   receiver_user_info
+0x0990  UTF16LE wstr  text                 dest 512 bytes, 256 wchars
size   2448+2*(n+1)
```

Both UserInfo blocks must be sent in FULL even though the client only reads +0x000
player_id and +0x486 nickname from each. The client compares its own id against
receiver_user_info[0] to pick the partner.
5 whisper windows exist, if all are busy the packet is silently dropped.

## C2S WhisperSend

```
+0x00  u32           target_player_id
+0x04  UTF16LE wstr  text
size   4+2*(n+1)
```

NOT used by the `/w name msg` lobby form, which goes out as 0x00B4.
