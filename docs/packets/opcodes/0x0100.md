# 0x0100

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | QuestDiscardAck | sub_47F2C0 | QuestPackets::questDiscardAck | 4 | quest | PROVEN |
| C2S | QuestDiscardReq | sub_483F50 | QuestPackets::parseDiscardRequest | 4 | quest | PROVEN |

## S2C QuestDiscardAck and 0x0100 C2S QuestDiscardReq

```
+0x00  u32  quest_index
size   4 in BOTH directions
```

S2C REMOVES the row from the quest state list. The remover returns 0 on a miss so an
unknown index is safe here, unlike 0x0101 and 0x0102.
C2S precondition: the selected entry exists with state 1.
