# 0x002F

| Direction | Name | Client fn | Server symbol | Size | System | Status |
|---|---|---|---|---|---|---|
| S2C | no case, C2S only | none | NONE | n/a | lobby list | NO CASE |
| C2S | JoinRoomRequest | sub_480F30 | GameServer::handleWhisper, WRONG handler | 4+2*(n+1) | lobby list | PROVEN |

## C2S JoinRoomRequest

```
+0x00  u32           room_id
+0x04  UTF16LE wstr  password   builder copies at most 9 wchars, empty is 2 zero bytes
size   4+2*(pw+1)
```

THIS IS THE JOIN ROOM PACKET. The password prompt only pops when the row has_password
field is 1 AND role byte_1A20B21 <= 1, so a GM joins with an empty password.
MSG_WAIT is up. There is NO S2C case 47, answer with the 0x0013 room context chain.

## Our server

`GameServer::handleJoinRoom` in `server/game/src/GameServerRoomHandlers.cpp`, the
`case 0x2F` of `GameServerDispatch.cpp`. It reads the room id and the wide password, refuses
a missing, playing, full or wrong password room with a 0x02 text box, seats the player, then
`GameServer::sendRoomScreen` for the [0x0013](0x0013.md) chain and
`GameServer::announceRoomJoin` so the peers get 0x32 then 0x21 for the new slot. No 0x3F
and no 0x63.
