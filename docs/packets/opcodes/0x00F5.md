## S2C ScenarioStart

```
+0x00  u32  scenario_key   matched against a 0x00F3 rec+0x04
+0x04  u32  counter_value  -> 0x01A20B14, the gold counter
size   8
```

NULL DEREF RISK: the lookup result is dereferenced with NO null check, an unknown key
crashes the client. The 0x00F3 definition MUST already be in the container.
If either the character def or the kart def fails to resolve the stage push never happens
and the client sits on MSG_WAIT.

## C2S ScenarioStageSelect

```
+0x00  u32  scenario_key   from the selected 0x00F4 progress row
size   4
```

Client gate: the NEXT row either does not exist or is cleared. MSG_WAIT is up and only the
`sub_4538B0` inside S2C 0x00F5 clears it. See CONFLICTS C6 on the scenario vs quest naming.
