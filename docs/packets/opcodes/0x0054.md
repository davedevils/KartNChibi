## S2C GameServerHandoff

```
+0x00  u32         unknown     read, never used
+0x04  ASCII cstr  ip          dest 256 byte stack buffer
 var   u32         port        read as 4 bytes into a u_short[2], only the low 16 bits used
size   8+strlen(ip)+1
```

IP IS ASCII, NOT UTF16. On connect success the client sleeps 1000 ms then re logins with
C2S 0x07 or 0xA7 and target_stage 8. Only needed when the race server differs from the
room server. Different opcode from 0x0019, do not confuse the two redirects.
